# CHRISS Music Website

This folder is ready to upload to a GitHub repository.

## Files

- `index.html` — website structure
- `style.css` — visual design
- `script.js` — music player
- `audio/` — put your MP3 files here

## Add music

The player is configured to use the playable files already in `audio/`:

- `Stress.mp3`
- `The_Stuff.mp3`
- `GS.mp3`
- `Continum_1.mp3`
- `Continum_2.mp3`
- `Homeless.mp3`
- `GoodBy.m4a`

When adding a release, upload a complete audio file to `audio/` and add its
exact filename to the `tracks` array in `script.js`.

## GitHub Pages

After uploading the files to a GitHub repository:

1. Open the repository's **Settings**.
2. Open **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select your main branch and the `/ (root)` folder.
5. Save.

GitHub Pages should then publish `index.html` as the site.

## Social links

The BandLab, YouTube, Spotify, and Instagram buttons link to their respective
platforms. Replace those URLs in `index.html` with your profile URLs when they
are available.
